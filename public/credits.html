Made by

Design, code, procedural art, music and sound: Tho Nguyen.

Original content

  • 3D scenery and characters: generated at runtime by the game's own code (low-poly geometry). No 3D model files are used.
  • Music: "Moonlit Grove", an original generative score (66 BPM, piano, music box, pads and glass bells) synthesized live with the Web Audio API.
  • Sound effects and ambience: wind, leaves, fireflies, footsteps and chimes, all synthesized in code. No audio files are used.
  • Fonts: none are shipped. Text uses your device's system fonts.
  • AI: development was assisted by AI coding tools. The game contains no AI-generated images, music or video. The narration in the demo video uses a synthetic voice (Kokoro TTS, open-weight model, Apache License 2.0).
